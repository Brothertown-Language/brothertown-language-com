# Brothertown Language

The Brothertown Language project website — an online home for BL learners,
with the reference surfaces linguists need to validate the work.

## Status

Repository bootstrap: conventions and docs only. The base Zola site setup is
tracked as issue 1 in the repository's issue tracker.

## Site scope

- **Dictionary** — entries generated from the validated data of record held in
  the research repositories, never hand-typed onto pages.
- **Lessons** — written, written+audio, and audio-only tiers.
- **Apps** — flashcards and games (JS builds and Godot web exports); apps carry
  their word lists inside them at release time.
- **Methodology / reference** — the research paper, correspondence tables, and
  per-source orthography profiles for linguist review.
- **Blog** — progress and approach articles.
- **About** — project, ethics, and provenance.

## Conventions

- Nation sovereignty respected throughout; AI-contributed changes are clearly
  marked.
- Site content renders from the data of record at build time; provisional
  entries carry their status labels.
